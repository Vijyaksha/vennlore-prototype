- LlamaIndex rework, quality fix: the original `entities=Literal["METHOD"]` / `kg_validation_schema={"METHOD": ["USES_METHOD"]}` schema structurally drops talks with a single (or otherwise unpaired) method. `SchemaLLMPathExtractor` only surfaces entities that appear in a *valid* triplet, and `_prune_invalid_triplets` prunes any triplet where `subject.lower() == obj.lower()` (self-reference) — with only one entity type, a lone method has no distinct partner to form a valid METHOD--USES_METHOD-->METHOD triplet with, so it never reaches `KG_NODES_KEY` at all. Fixed by introducing a second, fixed entity type: `entities=Literal["WORK","METHOD"]`, `kg_validation_schema={"WORK": ["USES_METHOD"]}`, with `EXTRACT_PROMPT` instructing the LLM to always emit the subject as a single node named "THIS_WORK" and the object as the METHOD. A lone method now forms a valid WORK->METHOD triplet regardless of how many other methods are present. `extract_methods_li`'s harvesting logic was unchanged (already filtered to `entity.label == "METHOD"`, so WORK entities are already ignored) — pinned with a new regression test using a fake WORK+single-METHOD annotation.

- Walk engine (2026-08-30): room cluster parsing = the run of leading purely-alphabetic tokens of length >= 2 (regex `^[A-Za-z]{2,}$` per token). This yields "Exhibit Hall" for "Exhibit Hall D, E & F, Level 2" (stops at "D,"), "Meeting Room" for "Meeting Room 708/710", and whole-name clusters for digit-free rooms like "Agate". Single-letter suffix rooms ("Bellco Theatre A" vs "Bellco Theatre B") therefore share a cluster with null floors and get the 10-minute same-cluster buffer.
- Walk engine (2026-08-30): floor = the first digit character appearing after the cluster prefix anywhere in the remainder (so "708/710" -> 7, "Level 2" -> 2). Rule precedence in `walkMinutes`: identical non-null building+room (5) > either building "Offsite" (60) > any null building/room (15) > different buildings (22) > same cluster+floor (10) > same building otherwise (15). Consequence: two talks in the same offsite room get 5, an "Offsite" building with a null room still gets 60.
