# Field notes — social sciences & education

Companion to `census-methodology.md`, which stays general. This file holds only what is true of
**social sciences and education** and would be noise in the general method. Read both before working
a social-sciences row; add what you learn here, not there.

Started 2026-09-14. Sections 1–6 are the pilot researcher's report from phase-2 wave 1 (30 rows, one
Opus agent, **10 searches, 21 of 30 rows at zero searches**). There was no index pass before this
wave: unlike CS/AI and engineering, this field has almost no deposit-index coverage, so the pilot
started from the society artefacts.

## The unit, the bar, and the scope

Accepted contributed presentations = **papers + posters accepted for one edition**; invited,
plenary, keynote, presidential and award presentations excluded; roundtables and author-meets-critics
with no submitted papers excluded; withdrawn excluded. ≥1,500 counted = VERIFIED; 800–1,499 =
BORDERLINE; below 800 **on positive evidence** = OUT. A stated total never beats a countable
artefact. Inferred or organiser-stated never reaches VERIFIED.

**THE PANEL RULE IS THE WHOLE BALL GAME IN THIS FIELD** (Rupert, settled 2026-09-12). Social-science
programmes are built from panels and organised sessions, not poster halls. Each paper inside a panel
counts as one. Every artefact in this wave supports this directly — papers are individually titled
records with their own authors inside every one of the counted programmes. Counting sessions instead
of papers would understate this field by **3–4×**: ECPR is 2,077 papers in 539 panels, LASA 4,609 in
1,671, APSA 5,570 in 1,295, ASSA 2,210 in 478.
